# Тестовый запуск раздела новостей

## Схема, под которую подготовлен проект

- Основной сайт остаётся статическим и размещается в корне нового сайта: `index.html`, `assets/` и PHP-обработчик форм `api/lead.php`.
- WordPress размещается отдельно по адресу `/news/` на **том же домене**. Его база данных и загруженные файлы остаются на хостинге и не входят в этот репозиторий.
- Тема `wordpress/ats-news/` выводит список и страницы новостей в стиле основного сайта. Стили и логотип она загружает из корня нового сайта.
- Архив `wordpress/ats-static-site.zip` содержит ссылки «Новости» на `/news/`. Рабочие файлы репозитория сейчас настроены для двух локальных сайтов LocalWP и ведут на `http://astru-news.local/`. Публичной ссылки на вход в WordPress нет.
- `wordpress/ats-news-theme.zip` содержит **только тему**. При существующем WordPress загружайте его через «Внешний вид → Темы → Добавить → Загрузить тему» либо распакуйте в `news/wp-content/themes/`, получив `ats-news/`. Не распаковывайте полный экспорт LocalWP поверх WordPress хостинга: локальная база содержит тестовые записи и адреса `*.local`.

Если WordPress уже установлен в корне домена или на другом домене, сначала уточните схему размещения. Не загружайте `index.html` поверх работающего WordPress: результат зависит от настроек веб-сервера. Для поддомена ссылки `/news/` в `index.html` и `assets/js/pages.js` нужно заменить на полный адрес раздела. В настройке темы «Адрес основного сайта» укажите адрес статического сайта.

## Развёртывание на новом сайте

1. Сделайте резервную копию текущих файлов и базы данных тестового сайта.
2. Убедитесь, что WordPress установлен в каталоге `/news/`, а корень домена доступен для размещения статического сайта.
3. Распакуйте `wordpress/ats-static-site.zip` в корень домена. Внутри `index.html`, `assets/` и `api/lead.php`. Для реальной отправки форм настройте почту по [инструкции](forms-local-testing.md). Архив старого сайта, `docs/` и исходники темы туда не нужны.
4. В WordPress откройте **Внешний вид → Темы → Добавить → Загрузить тему**. Установите архив `wordpress/ats-news-theme.zip` и активируйте тему. Архив можно пересоздать из папки `wordpress/ats-news/`.
5. В **Внешний вид → Настроить → Связь с основным сайтом** укажите полный адрес основного сайта с `https://`, например `https://test.example.ru/`. Если настройки «Настроить» нет, проверьте, что активирована именно тема «АвиаТехноСофт — Новости».
6. В **Настройки → Чтение** выберите показ последних записей. В **Настройки → Постоянные ссылки** выберите «Название записи» и сохраните. Новость должна открываться по адресу вида `/news/название-записи/`.
7. В **Настройки → Общие** задайте название сайта и часовой пояс компании. В **Настройки → Обсуждение** отключите комментарии к новым записям, если они не нужны.
8. Создайте отдельную учётную запись сотрудника с ролью **Автор**. Для администрирования WordPress используйте отдельную учётную запись.
9. В **Медиафайлы → Добавить** проверьте лимит размера файла. Загрузите пробные фото и видео, затем создайте пробную запись с заголовком, анонсом, обложкой и медиа в тексте.
10. Проверьте список `/news/`, страницу записи, переходы между новостями и основным сайтом, мобильное меню и воспроизведение видео. После проверки удалите пробную запись.

## Перед публичным запуском

- Настройте регулярную копию базы WordPress и каталога загруженных файлов; проверьте восстановление.
- Назначьте ответственного за обновление WordPress и темы.
- На время тестирования закройте тестовый сайт от поисковой индексации средствами хостинга или WordPress; перед запуском снимите ограничение.
- Проверьте утверждённые тексты и права на фотографии и видео.

Формы основного сайта работают через `api/lead.php`; WordPress к их отправке не привязан. Локальную и реальную доставку проверяйте по [инструкции](forms-local-testing.md).
