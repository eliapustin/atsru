# Журнал работ по сайту «АвиаТехноСофт»

Сопутствующий файл к [site_plan.md](site_plan.md). Обновляется при изменении решения, кода, результата проверки или открытого вопроса.

## Текущее состояние

Рабочий сайт — статический HTML/CSS/JS с PHP-обработчиком форм. Новости тестируются в отдельном LocalWP WordPress `astru-news.local`; основной сайт — `atsru.local`. Тема WordPress и публичные ссылки подготовлены. Четыре формы отправляют данные в PHP-обработчик; получатель заявок по умолчанию — `liap1990@gmail.com`, а публичный адрес сайта — `aviatechnosoft@yandex.ru`. Реальную доставку на хостинге ещё нужно настроить.

## Решения

| Дата | Тема | Решение |
| --- | --- | --- |
| 06.10.2026 | Новости | WordPress редактирует только новости; основной сайт остаётся статическим. Локально два домена, на хостинге планируется `/news/`, если размещение подтвердится. |
| 06.10.2026 | Формы | Один PHP-обработчик на домене основного сайта обслуживает четыре типа заявки. Локальная почта проверяется через Mailpit сайта `atsru`; реальная доставка настраивается на хостинге. |
| 06.10.2026 | Конфигурация почты | Получатель по умолчанию — публичный адрес компании; для внешнего сайта требуется подтверждённый адрес отправителя из переменной окружения. Секреты не хранятся в репозитории. |
| 06.10.2026 | Временный получатель заявок | По запросу владельца адрес получателя форм изменён на `liap1990@gmail.com`. Публичные адреса и ссылки `mailto:` остались `aviatechnosoft@yandex.ru`. Переменная `ATS_LEAD_TO` и приватный конфигурационный файл могут переопределить получателя. |
