# План развития сайта «АвиаТехноСофт»

## Текущая ветка: полный сайт на WordPress (08.10.2026)

Владелец отказался от схемы «статический сайт + WordPress в `/news/`» из-за невозможности запустить существующую установку `/news/`. Рабочих новостей и медиа для переноса нет. Новая цель — один WordPress в корне домена, тема `wordpress/ats-site`; инструкция [wordpress-full-site.md](../docs/wordpress-full-site.md). Исторический план ниже относится к предыдущему варианту.

| Шаг | Готово, когда | Статус |
| --- | --- | --- |
| Тема полного сайта | Все разделы имеют обычные адреса, новости через записи, формы и медиа включены | код подготовлен; требуется локальная проверка в WordPress |
| Локальная проверка | Тема активирована на новом WordPress, пройдены страницы, новости, четыре формы и мобильное меню | владелец подтвердил, что сайт в LocalWP работает; состав проверок не уточнён |
| Тестовый хостинг | Корневой WordPress работает на тестовом домене без 403, письма приходят | ждёт развёртывания |
| Публикация | Бэкап сделан, домен переключён, старые URL и юридический текст проверены | ждёт установки корневого WordPress на хостинге |

Рабочий план для изменений в этом репозитории. Решения, проверки и открытые вопросы фиксируются в [site_worklog.md](site_worklog.md). Статусы: `—` · `в работе` · `готово` · `ждёт проверки` · `отложено`.

## Правила работы

- Изменения основного сайта ведём в `index.html`, `assets/` и серверных файлах репозитория; локальные копии LocalWP синхронизируем после проверок.
- Рабочие локальные адреса (`*.local`) не должны попадать в архив для хостинга. Перед выпуском сверять адрес WordPress и ссылки.
- После каждого изменения обновлять этот план и журнал. Решения, влияющие на публикацию и эксплуатацию, записывать явно.
- Минимальная проверка: синтаксис JS/PHP, формы четырёх типов, переходы между статическим сайтом и WordPress, мобильный экран, ошибка сети и ограничение повторных отправок.
