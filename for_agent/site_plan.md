# План развития сайта «АвиаТехноСофт»

Рабочий план для изменений в этом репозитории. Решения, проверки и открытые вопросы фиксируются в [site_worklog.md](site_worklog.md). Статусы: `—` · `в работе` · `готово` · `ждёт проверки` · `отложено`.

## Правила работы

- Изменения основного сайта ведём в `index.html`, `assets/` и серверных файлах репозитория; локальные копии LocalWP синхронизируем после проверок.
- Рабочие локальные адреса (`*.local`) не должны попадать в архив для хостинга. Перед выпуском сверять адрес WordPress и ссылки.
- После каждого изменения обновлять этот план и журнал. Решения, влияющие на публикацию и эксплуатацию, записывать явно.
- Минимальная проверка: синтаксис JS/PHP, формы четырёх типов, переходы между статическим сайтом и WordPress, мобильный экран, ошибка сети и ограничение повторных отправок.
