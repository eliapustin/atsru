# План развития сайта «АвиаТехноСофт»

Один WordPress в корне домена `https://aviatechnosoft.ru` (без `www`), тема `wordpress/ats-site`; инструкция — [wordpress-full-site.md](../docs/wordpress-full-site.md). Решения, проверки и открытые вопросы фиксируются в [site_worklog.md](site_worklog.md). Прежний план (схема «статический сайт + `/news/`», блокеры хостинга) — в [site_plan_archive.md](site_plan_archive.md).

Статусы: `—` · `в работе` · `готово` · `ждёт проверки` · `ждёт заказчика` · `отложено`.

## Правила работы

- Тексты страниц правятся в исходниках (`assets/js/*.js`, `index.html`), затем `node wordpress/build-site-pages.js` и `python wordpress/package-theme.py`; на хостинг идёт только тема.
- Локальные адреса (`*.local`) не должны попадать в архив темы.
- Минимальная проверка: страницы, новости, мобильное меню, четыре формы заявок (~390 и ~1440 px).
