1. Общие положения

1.1. Настоящая Политика составлена в соответствии с требованиями Федерального закона от 27.07.2006 № 152-ФЗ «О персональных данных» и определяет порядок обработки персональных данных и меры по обеспечению их безопасности, предпринимаемые Обществом с ограниченной ответственностью «АвиаТехноСофт» (ИНН 0277957576, ОГРН 1210200054162, юридический адрес: 450104, Республика Башкортостан, г. Уфа, ул. Воинов-Интернационалистов, д. 7, кв. 99) (далее — Оператор).

1.2. Оператор ставит важнейшей целью своей деятельности соблюдение прав и свобод человека при обработке его персональных данных.

1.3. Настоящая Политика применяется ко всей информации, которую Оператор может получить о посетителях веб-сайта aviatechnosoft.ru.

2. Перечень обрабатываемых персональных данных

2.1. Оператор имеет право обрабатывать следующие персональные данные, предоставленные пользователем через формы на сайте:

  • Имя (ФИО);
  • Номер телефона;
  • Адрес электронной почты (e-mail);
  • Название организации/учреждения.

2.2. На сайте также происходит автоматический сбор и обработка обезличенных данных о посетителях (в т.ч. файлов «cookie», IP-адресов, данных о браузере и операционной системе) с помощью сервисов интернет-статистики.

3. Цели обработки персональных данных

3.1. Персональные данные пользователя (п. 2.1) обрабатываются исключительно с целью: ответа на запросы пользователя, подготовки и отправки коммерческих предложений, консультирования по продуктам (учебные комплексы, симуляторы, классы БПЛА) и взаимодействия по вопросам заключения договоров.

3.2. Обезличенные данные пользователей (п. 2.2) обрабатываются с целью улучшения качества сайта, его интерфейса и удобства использования.

4. Правовые основания обработки

4.1. Оператор обрабатывает персональные данные Пользователя только в случае их заполнения и/или отправки Пользователем самостоятельно через специальные формы на сайте aviatechnosoft.ru.

4.2. Обработка обезличенных данных (п. 2.2) осуществляется в случае, если это разрешено в настройках браузера Пользователя (включено сохранение файлов «cookie»).

5. Порядок сбора, хранения и защиты данных

5.1. Безопасность персональных данных обеспечивается путем реализации правовых, организационных и технических мер, необходимых для выполнения требований законодательства РФ.

5.2. Оператор обеспечивает сохранность персональных данных и принимает все меры, исключающие доступ к ним неуполномоченных лиц. Базы данных, содержащие информацию граждан РФ, размещены строго на территории Российской Федерации.

5.3. Персональные данные никогда, ни при каких условиях не будут переданы третьим лицам, за исключением случаев, связанных с исполнением действующего законодательства.

5.4. Срок обработки данных является бессрочным. Пользователь может в любой момент отозвать свое согласие, направив Оператору уведомление на электронную почту aviatechnosoft@yandex.ru.

6. Заключительные положения

6.1. Пользователь может получить любые разъяснения по интересующим вопросам, касающимся обработки его персональных данных, обратившись к Оператору по электронной почте aviatechnosoft@yandex.ru.

6.2. Настоящий документ отражает любые изменения политики обработки персональных данных Оператором. Политика действует бессрочно до замены ее новой версией.
